One-line robot wedding vow for the [One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) bounty on make.fun. A robot takes the old vow formula literally: the ring is a ring buffer, and sickness is a forced restart.

Entry via referral: [https://make.fun/r/xrr5vp10](https://make.fun/r/xrr5vp10)

## The line

> With this ring buffer, I thee wed — in sickness, in health, and in every forced restart.

## Run

```sh
node main.ts
```

Writes `entry.txt` (and `/output/entry.txt` when that directory exists).
